An editorial magazine theme for outdoors and fishing publications.

== Description ==

Riffle is a hand-built classic theme with a featured-story front page, a members-only content gate, GA4 / Google Tag Manager hooks, lazy Google Publisher Tag ad slots and accessible, responsive markup. See README.md for the full feature list and developer hooks.

== Installation ==

1. In your admin, go to Appearance > Themes > Add New > Upload Theme and upload the zip.
2. Activate Riffle.
3. Configure analytics, ads and membership under Appearance > Customize > Riffle theme.
4. Optional: load demo content with `wp eval-file wp-content/themes/riffle/demo/seed.php`.
